# STANGA — תוכנית שלב ב׳ (גרסה 0.2.0)

## המטרה

להוסיף משחק מקומי אמיתי לשני שחקנים על אותו מכשיר, ולשפר את תחושת המשחק,
מבלי לשבור דבר מגרסה 0.1.0.

## העיקרון המנחה

**אין לוגיקה נפרדת למשחק המקומי.** מצב המשחק נגד המחשב ומצב שני השחקנים הם
אותו קוד בדיוק, ונבדלים רק בהרכב רשימת ה־`PlayerSlot`:

```
משחק נגד המחשב:   [ Slot(home, HumanController), Slot(away, AIController) ]
שני שחקנים:        [ Slot(home, HumanController), Slot(away, HumanController) ]
אונליין (שלב ג׳):  [ Slot(home, HumanController), Slot(away, NetworkController) ]
```

```
Controller  →  PlayerCommand  →  MatchSession  →  MatchEngine (60Hz קבוע)  →  MatchState
```

הסימולציה לעולם אינה יודעת מאיזה התקן הגיעה הפקודה.

## מנות העבודה

| #   | מנה               | תוצר עיקרי                                                          |
| --- | ----------------- | ------------------------------------------------------------------- |

| 11  | בדיקות ותיעוד     | בדיקות שלב ב׳, README, CHANGELOG, מסמכי docs                        |

## החלטות שהתקבלו מראש

1. **שמות השדות של `PlayerCommand` נלקחים מהמפרט** (`moveX`, `moveY`, `aimX`,
   `aimY`, `shootHeld`...). זהו שינוי שם ל־API הפנימי, ולכן כל המשתמשים וכל
   הבדיקות מתעדכנים באותה מנה.
2. **`lofted` הוא מצב של השחקן, לא של ההתקן.** ב־0.1.0 הוא ישב ב־`InputManager`.
   עם שני שחקנים לכל אחד סוג בעיטה משלו, ולכן הוא עובר ל־`PlayerState`
   וה־`Controller` שולח בקשת החלפה (`lobToggle`) בלבד.
3. **`aimX`/`aimY` הם וקטור ולא זווית.** וקטור אפס פירושו "שמור על הכיוון הנוכחי",
   וכך אין צורך בערך קסם.
4. **המקלדת המפוצלת היא שני התקנים לוגיים נפרדים** (`keyboard-left`,
   `keyboard-right`), ולכן כלל "התקן אחד לא ישלוט בשני שחקנים" נשמר ללא חריג מיוחד.
5. **אין split screen.** מצלמה משותפת אחת, כנדרש, וכך גם אין רינדור כפול.
6. **ברירת המחדל של הרטט משתנה לכבוי**, לפי דרישת הנגישות.
7. **מיגרציה של הגדרות**: המפתח `stanga.settings.v1` נקרא כמו שהוא וממוזג עם
   ברירות המחדל החדשות. משתמש מ־0.1.0 לא מאבד דבר.

## מה בוצע בפועל

כל אחת עשרה המנות בוצעה. שינויים והחלטות שהתקבלו תוך כדי, מעבר לתוכנית המקורית:

| נושא          | מה קרה                                                                                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `isHuman`     | התברר שהוא היה קבוע בזמן יצירת המצב, ולכן השחקן השני נחשב "לא אנושי" ולא קיבל מדי כוח או סמן. הועבר לבעלות `MatchSession`.                                           |
| מצלמה משותפת  | הנוסחה הראשונה למרחק התעלמה מכך שמצלמה מוטה דוחסת עומק. הוחלפה בפתרון מול מטריצת ההיטל האמיתית, עם הרחבת זווית ראייה כשהמרחק לבדו אינו מספיק.                        |
| גבול המסגור   | נמדד ולא נוחש: שני השחקנים והכדור נשמרים במסגרת עד מרחק של 20 מטר ביניהם. מעבר לכך תקרות המרחק והזווית מנצחות, והמצלמה שומרת על הכדור. מתועד ב־README וב־GameConfig. |
| כפתור השהיה   | חפף את מדי השחקן השני. הוצא מ־`position: absolute` אל תוך שורת ה־HUD.                                                                                                |
| בדיקות שלב א׳ | לא נמחקו ולא הוחלשו. שתי בדיקות עודכנו בגלל שינוי מכוון בהתנהגות (ברירת המחדל של הרטט), עם הערה המסבירה למה.                                                         |
