# מערכת הבעיטות

<div dir="rtl">

מסמך זה מתאר את מערכת הבעיטות כפי שהיא מגרסה 0.5.0, ואת הסיבה שבגללה היא
נכתבה מחדש. הקוד עצמו יושב ב־`src/game/ShotResolver.ts`,
`src/game/BallFlight.ts` ובבלוק `kick` שב־`src/config/GameConfig.ts`.

## מה היה שבור

הדגם הקודם חישב **דחף קדימה** ואז הוסיף מעליו **מקדם הגבהה** — כלומר
`impulseY = forward * lift`. שתי תוצאות נבעו מכך, ושתיהן נמדדו:

| כוונת | זווית שיגור | עוצמת הדחף |
| ----- | ----------- | ---------- |
| -1.00 | 1.7°        | 9.40 Ns    |
| 0.00  | 13.0°       | 9.65 Ns    |
| 1.00  | 43.5°       | 12.97 Ns   |

1. **טווח הזוויות היה חסר תועלת.** 1.7° למטה פירושו כדור שנדחס לאספלט.
2. **הגובה ייקר את הבעיטה.** אותה טעינה נתנה דחף גדול ב־38% בכוונת הגבוהה,
   ולכן לא היה שום אופן לחזור על בעיטה.

## הדגם הנוכחי

בעיטה היא **מהירות** ו**זווית שיגור**, ושתיהן בלתי תלויות:

```
elevation = minElevation + share(style, verticalAim) * (maxElevation - minElevation)
speed     = (minSpeed + power * (maxSpeed - minSpeed))
          * styleSpeedScale
          * (1 - elevationSpeedFalloff * steepness)
          * (volley ? volleySpeedScale : 1)
          + runSpeed * runShare
```

- `minElevation` = 5°, `maxElevation` = 50°. כל בעיטה במשחק נמצאת בטווח הזה.
- `elevationSpeedFalloff` — בעיטה תלולה מוותרת על עוצמה. אי אפשר להכניס את
  הרגל מתחת לכדור ולהעביר אותה במלוא המהירות באותו זמן.
- `runSpeed * runShare` — ריצה אל הכדור שווה משהו, אך לא הכול.

**הבעיטה קובעת את מהירות הכדור ולא מוסיפה אליה.** רגל שעוברת דרך כדור מכריעה
את התנע שהיה לו, וזה הדגם היחיד שבו אותה טעינה ואותה כוונת נותנות פעמיים את
אותה בעיטה — מה שנדרש כדי לכוון למשקוף בכוונה.

## חמשת הסגנונות

כל סגנון ממפה את הכוונת (-1..1) לחלון משלו בתוך טווח ה־5°–50°. הכוונת עדיין
מזיזה את הכדור בתוך החלון, ולכן סגנון הוא **הילוך** ולא ערך קבוע.

| סגנון  | חלון הזוויות | עוצמה | סיבוב             |
| ------ | ------------ | ----- | ----------------- |
| רגילה  | 5°–50°       | 100%  | לפי הבקשה         |
| שטוחה  | 5°–13°       | 106%  | חלש               |
| מוגבהת | 30°–50°      | 94%   | בינוני            |
| מסובבת | 6.5°–36.5°   | 95%   | ×1.25, ורצפה 0.55 |
| צ׳יפ   | 43°–50°      | 62%   | חלש               |

ל**מסובבת** יש רצפת סיבוב: לבחור את הסגנון ולקבל כדור ישר היה הופך אותו
לתווית במקום לבעיטה.

**וולה** אינה סגנון נבחר אלא תיאור של מה שקרה: כדור שנבעט מגובה
`kick.volleyHeight` ומעלה יוצא נקי יותר ומעט גבוה יותר.

**לחיצה קצרה** — מתחת ל־`kick.tapSeconds` — היא נגיעה רכה בזווית המינימלית,
בלי קשר למקום שבו נשארה הכוונת.

## מודל המעוף

`BallFlight` הוא המודל היחיד, ושלושה קוראים לו:

1. **הסימולציה** מחילה אותו על גוף הפיזיקה.
2. **היריב** מחזה איתו לאן הכדור יגיע.
3. **קו החיזוי** מצייר איתו את הקשת שהשחקן עומד לבעוט.

זה אינו סידור אלא נכונות: חיזוי שמחושב מדגם אחר שולח את היריב למקום הלא נכון,
וקו חיזוי שמצויר מדגם אחר מבטיח קשת שהכדור לא עושה.

- **גרר אוויר ריבועי**, `0.5 * rho * Cd * A / m`, פועל תמיד.
- **התנגדות גלגול** פועלת רק כשהכדור על הקרקע.
- **מגנוס** פועל רק באוויר, ודועך יחד עם הסיבוב.

Havok אחראי לקפיצה, לחיכוך ולהתנגשויות. הריסון הליניארי שלו הורד כמעט לאפס
בכוונה: הוא גזל את אותו שבר מכדור שעף ומכדור שמתגלגל, ואלה חוקים שונים.
