# STANGA — תוכנית מימוש לגרסה 0.1.0

## מטרה

אב־טיפוס משחקי מלא: שחקן אנושי אחד מול יריב ממוחשב אחד, מגרש רחוב תלת־ממדי,
משחק בן 3 דקות, ניקוד סטנגה (שער/קורה/משקוף/חיבור), דפדפן מחשב וטלפון.

## החלטות ארכיטקטורה

1. **הפרדת שכבות מוחלטת** בין סימולציה לרינדור.
   `MatchState` הוא מבנה נתונים טהור הניתן לסריאליזציה (`JSON`) וללא הפניות ל־Babylon.
2. **Fixed timestep** של 60Hz עם accumulator. הרינדור רץ בקצב הדפדפן ומושך מצב מוכן.
   הצעד האוטומטי של Babylon מנוטרל, `SimulationLoop` הוא זה שמקדם את הפיזיקה.
3. **מודל פקודות אחיד** (`InputCommand`). גם השחקן המקומי וגם ה־AI מייצרים את אותו
   מבנה. בשלב האונליין אותו מבנה יגיע מהרשת ללא שינוי בסימולציה.
4. **חוקי המשחק טהורים**. `ScoringSystem`, `MatchClock` ו־`MatchRules` הם TypeScript
   נקי ללא תלות במנוע — ולכן ניתנים לבדיקה ב־Vitest ללא דפדפן.
5. **GameConfig יחיד** — כל מספר שמשפיע על משחקיות נמצא שם.

## מה במפורש מחוץ לתחום בשלב 1

שרת רשת, rollback/prediction, שוערים, 2v2, קריירה, טורנירים, חשבונות משתמש.
