# נכסי צד שלישי

## הרשימה המלאה

**אין.**

ב־STANGA אין ולו נכס אמנותי אחד שהגיע מבחוץ: אין מודלים, אין טקסטורות, אין
סאונדים מוקלטים, אין גופנים מותקנים ואין קבצי HDR. כל מה שנראה ונשמע במשחק
נוצר בזמן ריצה מתוך הקוד שבמאגר הזה.

מסמך זה קיים כדי שהתשובה תהיה מתועדת ולא משתמעת, וכדי שברגע שנכס חיצוני
כלשהו יתווסף — הוא יירשם כאן עם הרישיון שלו לפני שהוא נכנס לבנייה.

## מה זה אומר בפועל

| מה          | איך נוצר                                                          | היכן בקוד                                                       |
| ----------- | ----------------------------------------------------------------- | --------------------------------------------------------------- |
| טקסטורות    | Canvas 2D בזמן ריצה                                               | `src/rendering/ProceduralTextures.ts`                           |
| דמויות      | גאומטריה פרימיטיבית (קפסולות, גלילים, תיבות) + אנימציה פרוצדורלית | `src/rendering/PlayerView.ts`, `src/entities/PlayerAnimator.ts` |
| מגרש וסביבה | גאומטריה פרימיטיבית + טקסטורות פרוצדורליות                        | `src/rendering/Arena.ts`                                        |
| קהל         | thin instances של קפסולה אחת                                      | `src/rendering/Crowd.ts`                                        |
| תאורת סביבה | `ReflectionProbe` שמצלם את כיפת השמיים של הסצנה עצמה              | `src/rendering/Environment.ts`                                  |
| צליל        | סינתזה ב־Web Audio, בלי קובץ אחד                                  | `src/audio/AudioManager.ts`                                     |
| אייקונים    | נוצרים מסקריפט לתוך `public/icons`                                | `scripts/generate-icons.mjs`                                    |
| גופן        | גופן המערכת של המכשיר; שום גופן אינו מוטמע או מורד                | `src/styles/main.css`                                           |

## ספריות תוכנה

אלה קוד, לא נכסי אמנות, ורישיונותיהם מופיעים ב־`node_modules` של כל אחת.
הן מפורטות כאן לשלמות:

| חבילה                                                                          | רישיון     |
| ------------------------------------------------------------------------------ | ---------- |
| `@babylonjs/core`, `@babylonjs/havok`                                          | Apache-2.0 |
| `@colyseus/core`, `@colyseus/schema`, `@colyseus/ws-transport`, `colyseus.js`  | MIT        |
| `vite`, `vitest`, `typescript`, `eslint`, `prettier`, `tsx`, `vite-plugin-pwa` | MIT        |

## מה לעשות כשמוסיפים נכס

1. לוודא שהרישיון מתיר שימוש מסחרי והפצה, ולשמור עותק שלו במאגר.
2. לרשום שורה בטבלה הראשונה: מה הנכס, מאיפה, איזה רישיון, ומה נדרש בייחוס.
3. לעדכן את `docs/art-asset-pipeline.md` אם הנכס דורש שלב עיבוד.

**אסור בהחלט** להשתמש בנכסים של FIFA, EA, PES, eFootball או כל משחק מסחרי אחר,
ובכלל זה מודלים, טקסטורות, ערכות, סמלים, שמות שחקנים, שמות מועדונים וקולות
פרשנות — בין אם הם "נמצאו באינטרנט" ובין אם חולצו ממשחק. אין לכך רישיון,
ולא יהיה.
