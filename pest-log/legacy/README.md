# הגרסה הקודמת של היומן — קובץ מקור לשימור

`pest-log-single-file-app.html` הוא היומן שקדם למערכת הזו: אפליקציית
קובץ אחד (HTML + JavaScript) שעבדה מול `localStorage` ומול אחסון הענן של
Artifacts, והפיקה PDF בדפדפן עם html2canvas + jsPDF.

הקובץ נשמר כאן **כמקור היסטורי בלבד**. הוא אינו חלק מהאפליקציה, אינו
נבנה, אינו נבדק ואינו מוגש למשתמשים. הוא נשמר כדי שאפשר יהיה לחזור
ולבדוק מה בדיוק היה בגרסה הקודמת — ניסוח, סדר שדות, התנהגות — בזמן
שממשיכים לפתח.

מה הועבר ממנו למערכת הנוכחית, ומה לא הועבר במכוון, מתועד ב-
[`docs/ported-from-legacy-app.md`](../docs/ported-from-legacy-app.md).
