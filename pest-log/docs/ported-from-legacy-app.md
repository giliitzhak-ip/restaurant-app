# מה הועבר מהגרסה הקודמת של היומן

הגרסה הקודמת הייתה אפליקציית קובץ אחד (`legacy/pest-log-single-file-app.html`)
שעבדה מול `localStorage`, שמרה עותק בענן של Artifacts, והפיקה PDF בדפדפן.
המסמך הזה מפרט מה עבר ממנה למערכת הנוכחית, איפה זה נמצא עכשיו, ומה
**לא** הועבר — ולמה.

---

## מה שהועבר עכשיו

### 1. ספריות ניסוח („הוסף מתבנית”)

שבע הספריות של הגרסה הקודמת הועברו במלואן: ממצאי ניטור, נסיבות
ההחלטה על הדברה, פעולות מניעה, טיב ההדברה לפני ואחרי, אזהרות בסיום,
והערות לאחריות.

- הניסוחים המובנים: `src/schema/textLibraries.ts`
- הבורר (חיפוש, בחירה מרובה, הוספה לשדה): `src/components/TemplatePicker.tsx`
- התבניות של העסק: טבלת `text_templates` עם RLS (מיגרציה `0011`)
- **למידה אוטומטית**: בסיום יומן, כל ניסוח שהמדביר כתב בעצמו נשמר
  לספרייה שלו לפעם הבאה — בדיוק כמו `learnTemplates` בגרסה הקודמת
  (`collectLearnableTemplates`, מופעל מ-`CompletedPage`).

הניסוחים הם הצעה בלבד. המסך אומר במפורש שהם אינם מחליפים את תווית
התכשיר, ושזמן כניסה מחדש ואזהרות ייחודיות לתכשיר נקבעים לפי התווית.

### 2. טעינה מיומן קודם של אותו לקוח

בגרסה הקודמת: „יש יומן קודם #N” עם שתי אפשרויות — הכול, או תכשירים
בלבד. הועבר ל-`src/features/wizard/PreviousLogLoader.tsx` +
`loadPrevious.ts`, עם אותם כללים של שכפול היומן: **לעולם** אינם
מועתקים תאריך, שעה, חתימות, נ״צ, אצוות, מינונים, אישור האזהרות ומועד
המסירה.

### 3. תכשירים ואצוות מיומנים אחרונים

`RecentApplicationsPicker` מציג את התכשירים והאצוות מהיומנים האחרונים
שהושלמו, ומוסיף שורת יישום חדשה עם שם התכשיר, החומר הפעיל ושיטת
היישום. המזיק והמינון נשארים ריקים בכוונה. בנוסף, ליד שדה האצווה
מוצעות האצוות שנרשמו בעבר לאותו תכשיר — כהצעה לאימות מול האריזה.

### 4. מאגר תחנות האכלה וניטור לאתר

הגרסה הקודמת ניהלה תחנות ברמת האתר (סוג, צבע, מספור עוקב, „הוספת כמה
תחנות”, „סימון הכל כתקין”), ובכל יומן נרשם רק מצבן. הועבר לטבלת
`site_stations` + `src/features/wizard/SiteStationsSection.tsx`, עם שבעת
סוגי התחנות והצבעים המקוריים. הסרת תחנה מסמנת אותה כלא פעילה ואינה
משנה את המספור של האחרות.

### 5. הדבקת נ״צ מהמפות

כשה-GPS חסום או לא זמין, אפשר להדביק נ״צ או קישור מ-Google Maps או
מ-Waze. הפרסר הועבר כמות שהוא: `src/lib/legacy/coordinates.ts`.

### 6. אחריות

תקופת אחריות (מתוך אותה רשימה) והערות אחריות, כולל ספריית ניסוחים.
נשמר ב-`warranty` בתוכן היומן ומודפס ב-PDF, עם הבהרה שהאחריות היא
התחייבות מסחרית ואינה חלק מהדרישות המחייבות ביומן.

### 7. פירוט מזיק לפי נספח א׳

קרציות (קשות/רכות), יתושים (בוגרים/זחלים), טרמיטים (קרקע/עץ) וחיפושיות
(פירוט ברמת המשפחה). הכלל הועבר ל-`ANNEX_SUBTYPE_RULES`, השדה נוסף
לממצא, וההשלמה נחסמת כשהפירוט חסר.

### 8. סיווג תמונות

מפגע / פעולת מניעה / תיעוד כללי — נבחר לפני הצילום, נשמר לכל תמונה,
ומופיע ב-PDF מקובץ לפי סיווג.

### 9. סיכום ללקוח ב-SMS

`buildSmsSummary` בונה את אותו סיכום שהיה בגרסה הקודמת (מספר יומן,
תאריך, מקום, מזיקים, תכשירים, זמן כניסה מחדש, הנחיות, פרטי המדביר
ומספר מרכז ההרעלות). המסך אומר במפורש: הודעת טקסט אינה יכולה לשאת
קובץ — נשלח סיכום, ואם הופק PDF מצורף אליו קישור חתום.

### 10. „בדיקת מערכת”

מסך `/diagnostics` מריץ בדיקות אמיתיות: הגדרות סביבה, חיבור, התחברות,
IndexedDB, תור הסנכרון, מקום פנוי, פער השעון מול השרת, זמינות שירות
ה-PDF, שיתוף קבצים ותמיכה ב-PWA.

### 11. עיצוב המסמך

הלוגו הזהוב על רקע הירוק העמוק (`#1f5236` + `#b39c6a`) של הגרסה הקודמת
חזר לראש ה-PDF. שאר האפליקציה נשארת בשפה החזותית הירוקה שנבחרה
בעיצוב מסך הבית.

### 12. מאגר התכשירים של הגרסה הקודמת

151 התכשירים שהיו מוטבעים בקוד יוצאו לקובץ
`data/products-from-legacy-app.csv`. הם **אינם** נטענים אוטומטית. מי
שרוצה בהם מריץ:

```bash
npm run import:products -- \
  --file data/products-from-legacy-app.csv \
  --org <uuid> \
  --source "אפליקציית היומן המקומית הקודמת — לא אומת מול מקור רשמי" \
  --verified-at <התאריך שבו אימתתם>
```

כל השורות נטענות עם `registration_status = unknown`, ולכן האפליקציה
מציגה עליהן אזהרה עד שיאומתו מול המקור הרשמי.

## מה לא הועבר, ולמה

| מה | למה לא |
| --- | --- |
| רשימת 151 התכשירים כנתון עדכני בקוד | רשימה בקוד מתיישנת בשקט. היא זמינה כקובץ לייבוא מבוקר, עם מקור ותאריך אימות, ועם סטטוס „לא מאומת”. |
| הפקת PDF ב-html2canvas + jsPDF | התוצאה היא תמונה: הטקסט אינו ניתן לחיפוש והעברית מיטשטשת. ה-PDF מופק בשרת מ-HTML עם פונט מוטבע, וטקסט אמיתי. |
| `localStorage` כמסד הנתונים הראשי | מוגבל בגודל, נמחק בקלות, ואין בו הפרדה בין עסקים. המסד הוא Postgres עם RLS, והמכשיר מחזיק IndexedDB לעבודה ללא קליטה. |
| מחיקת יומן שהושלם מהלקוח | מחיקה מתבצעת כמחיקה רכה, בהרשאת מנהל, ורק לאחר תקופת השמירה. |
| מונה יומנים בצד הלקוח (`counter`) | המספר הסידורי מוקצה בשרת תחת נעילה, כדי שיישאר עוקב ובלתי חוזר גם בהשלמות מקבילות. |
