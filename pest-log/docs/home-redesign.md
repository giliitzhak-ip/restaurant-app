# עיצוב מחדש של מסך הבית

## מה השתנה

מסך הבית עוצב מחדש לרשת כפתורים עגולים בהשראת התמונה שנמסרה, והשפה
החזותית של האפליקציה כולה עברה משחור-זהב לירוק-בהיר.

**כל הפונקציות, הנתונים והמסכים הקיימים נשמרו.** לא הוסרה שום יכולת,
ולא שונתה סכמת בסיס הנתונים.

## השפה החזותית

| תפקיד | ערך |
| --- | --- |
| ירוק ראשי | `#16C956` |
| ירוק כהה | `#087A42` |
| רקע המסך | `#F5F7F8` |
| עיגולים / משטחים | `#FFFFFF` |
| טקסט ראשי | `#1B2520` |
| טקסט משני | `#66736C` |
| תג התראה | `#EF4444` |
| צל | `0 8px 24px rgba(20, 50, 35, 0.12)` |

כל הצבעים הם משתני CSS ב-`src/styles/theme.css`, ולכן **כל המסכים
הקיימים התעדכנו יחד** ונשארו עקביים — בלי לגעת בכל רכיב בנפרד.
האזור העליון מעוגל בתחתיתו (`border-radius: 0 0 28px 28px`).

## רשת הכפתורים

שמונה פעולות בשלוש עמודות, בסדר RTL:

| שורה | ימין | אמצע | שמאל |
| --- | --- | --- | --- |
| 1 | יומן חדש | טיוטות | ארכיון |
| 2 | לקוחות | תכשירים | משימות |
| 3 | פרופיל | הגדרות | — |

תחנות ההאכלה הוסרו ממסך הבית לבקשת המשתמש — הן אינן פעולה ראשית. המסך
`/bait-stations` נשאר במערכת ונפתח מתוך מסך ההגדרות, וגם התיעוד בתוך
האשף (שלב 4) לא השתנה.

- עיגול לבן ברוחב `clamp(100px, 27vw, 116px)`, אייקון ירוק במרכז, כותרת
  מתחת, צל רך, ושטח לחיצה של 132px לפחות.
- אייקונים אחידים מ-Lucide (`lucide-react`). אין אימוג׳י.
- מתחת ל-340px רוחב הרשת יורדת לשתי עמודות בלי להקטין את הכפתורים.
- "יומן חדש" הוא הפעולה הראשית: טבעת ירוקה, רקע מודגש וכותרת מודגשת.
  אין אנימציה מהבהבת.

## תגי מידע — נתונים אמיתיים בלבד

| תג | מקור הנתון |
| --- | --- |
| טיוטות | טיוטות מקומיות (IndexedDB) + טיוטות מהשרת, בלי כפילויות |
| משימות | טיפולים משלימים ביומנים שהושלמו, שמועדם הגיע או שאין להם מועד |
| ארכיון | ספירת יומנים שהושלמו מתחילת החודש (`count` בשרת) |

תג אינו מוצג כאשר המספר הוא אפס. ללא קליטה, מונה הטיוטות נשאר מדויק
(הוא מקומי) והשאר מגיעים מהמטמון האחרון.

**המשימות נגזרות מהיומנים עצמם** ולא מטבלה חדשה — כך לא נדרש שינוי
בסכמת בסיס הנתונים לצורך שינוי עיצובי, והמידע תמיד אמיתי.

## תנועה ומשוב

| אפקט | מימוש |
| --- | --- |
| לחיצה | כיווץ ל-0.95 למשך 100ms, האייקון עולה 3px, הצל קטן |
| ripple | אלמנט זמני שיוצא מנקודת הלחיצה ונמחק בסיום |
| רטט | `navigator.vibrate` כשנתמך בלבד |
| עיכוב ניווט | עד 100ms, חסום ב-180ms |
| מעבר מסך | 240ms, המסך הנכנס מחליק לפי כיוון RTL; חזרה בכיוון ההפוך |
| כניסת הכפתורים | fade + `translateY(12px)` עם stagger של 40ms |
| גלילה | האזור הירוק מתכווץ, הברכה נעלמת, כותרת דביקה מופיעה |

הכול ב-`transform` וב-`opacity` בלבד, בלי ספריית אנימציות. הגלילה
מעודכנת ב-`requestAnimationFrame` אחד, כדי לשמור על 60FPS.

**הפחתת תנועה:** תחת `prefers-reduced-motion: reduce` מבוטלים ה-ripple,
ה-stagger, ההזזות והרטט, ונשארת הנמכה קצרה בלבד.

## מסכים שנוספו

הכפתורים חייבים להוביל למסך אמיתי, ולכן נוספו שישה מסכים — כולם עם
נתונים אמיתיים, בלי כפתורי דמה:

| מסך | תוכן |
| --- | --- |
| `/drafts` | טיוטות מהמכשיר ומהשרת, כולל טיוטות ממכשיר אחר |
| `/tasks` | טיפולים משלימים, מחולקים ל"לביצוע" ו"מתוכננות" |
| `/products` | מאגר התכשירים, עם מקור מידע, תאריך אימות ואזהרות תוקף |
| `/bait-stations` | תחנות האכלה מקובצות לפי אתר (נפתח מההגדרות) |
| `/profile` | פרטי המדביר והרישיונות |
| `/settings` | סנכרון, נתוני ייחוס, שמירת מידע ויציאה |

## נגישות

- כל כפתור הוא `<button>` אמיתי עם `aria-label` בעברית, שכולל גם את
  משמעות התג ("טיוטות. יומנים שטרם הושלמו — 3 טיוטות פתוחות").
- ניווט מקלדת מלא, `focus-visible` ברור, וקישור "דילוג לתוכן הראשי".
- גודל טקסט 16px בטפסים, כדי למנוע זום אוטומטי ב-iOS.
- הודעת המרכז להרעלות נשארת קבועה ובולטת בכל מסך (דרישה 16).

## באגים שהתגלו בזמן העיצוב מחדש

| הבאג | מה קרה | התיקון |
| --- | --- | --- |
| `will-change` שובר `position: fixed` | `will-change: transform` קבוע על עוטף המסך יוצר containing block, ולכן הכותרת הדביקה, סרגל האשף והודעות ה-toast התמקמו לפי העמוד ולא לפי החלון | הרמז ניתן רק בזמן האנימציה |
| כותרת דביקה שתופסת מקום | `position: sticky` עם `opacity: 0` השאיר פס ריק מעל האזור הירוק | הוחלף ל-`position: fixed` |
| שם העסק נדבק לתת-הכותרת | שני `span` inline באותה שורה | `display: flex` על המכל |
| סף גלילה גבוה מדי | הרשת נכנסת כמעט במלואה במסך טלפון, טווח הגלילה כ-65px, והסף היה 72 — הכותרת הדביקה לא הופיעה לעולם | הסף הורד ל-44 |
| משימה שמועדה היום נחשבה סגורה | ההשוואה הייתה מול סוף יום היעד | השוואה מול תחילת יום היעד |
| שליחה כפולה בסנכרון | המפתח נרשם כ"בוצע" רק אחרי ההסרה מהתור, ובחלון הביניים נכנסה שליחה נוספת | הסימון קודם להסרה |
