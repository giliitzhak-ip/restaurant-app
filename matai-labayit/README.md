# מתאים לבית (שם זמני)

אפליקציית מובייל בעברית (RTL) שעוזרת לבחור מוצרים לבית תוך כדי סיבוב בחנויות:
מצלמים חדר, מצלמים מוצר בחנות (כל חנות – בלי קטלוג ובלי שיתוף פעולה), והמוצר מוצג על תמונת הבית
כדי לבדוק מראה, צבע, גודל ומיקום לפני הקנייה.

> כל הדמיה היא **להמחשה בלבד** – לא מדידה מדויקת ולא מציאות רבודה. האפליקציה מסמנת זאת במסך ובכל תמונה מיוצאת,
> ומציגה אזהרה "גודל משוער" כשאין מידות.

## הרצה מהירה

דרישות: Node.js 20+ (נבדק עם 22), npm. לטלפון: אפליקציית **Expo Go** (SDK 57), או Development Build.

```bash
cd matai-labayit
npm install              # מעתיק גם את canvaskit.wasm ל-public/ (נדרש רק לתצוגה בדפדפן)
npx expo start           # סרקו את קוד ה-QR עם Expo Go (אנדרואיד) או עם המצלמה (iPhone)
```

אפשרויות נוספות:

```bash
npx expo start --web     # תצוגה מקדימה בדפדפן (מומלץ במצב מובייל ב-DevTools)
npm run build:web        # בנייה סטטית לדפדפן לתיקייה dist/
npm run typecheck        # בדיקת טיפוסים
npx expo run:ios         # Development Build מקומי (דורש Xcode) – או:
npx eas-cli@latest build --profile development --platform all   # בנייה בענן של Expo
```

* **עברית מימין לשמאל:** ב-Development Build ה-RTL נקבע מראש (`expo-localization` עם `forcesRTL` ב-`app.json`).
  ב-Expo Go האפליקציה מפעילה RTL בעצמה; ייתכן שבהפעלה הראשונה צריך לסגור ולפתוח אותה פעם אחת כדי שהכיוון יתעדכן.
* **נתוני הדגמה:** במסך הפתיחה "לנסות עם חדר לדוגמה", או בהגדרות ← "טעינת חדר לדוגמה". ההסרה בלחיצה אחת
  (הגדרות ← "הסרת נתוני ההדגמה"). כל ישויות ההדגמה מסומנות `demo: true`, והקבצים ב-`assets/demo/` הם איורים שנוצרו לפרויקט.

## בחירת הסטאק – ולמה

| רכיב | בחירה | נימוק |
|---|---|---|
| מסגרת | **Expo (SDK 57) + React Native + TypeScript** | קוד אחד ל-iPhone ולאנדרואיד, בנייה בענן (EAS) בלי Mac, עדכונים באוויר, ותצוגה בדפדפן לבדיקות. |
| ניווט | **Expo Router** | ניתוב לפי קבצים (`src/app`), קישורים עמוקים. |
| עיבוד וציור | **@shopify/react-native-skia** | מנוע Skia (של Chrome/Android) על GPU: מצבי מיזוג (multiply/screen/dstIn), מטריצות פרספקטיבה, מסכות, מסנני צבע וצללים, קריאת פיקסלים ורינדור מחוץ למסך לייצוא. אותו קוד רץ ב-iOS, אנדרואיד ודפדפן. |
| מחוות | **react-native-gesture-handler** | גרירה, צביטה, סיבוב בשתי אצבעות. |
| אחסון | **AsyncStorage** (נתונים) + **expo-file-system** (תמונות) | הכול מקומי, בלי חשבון משתמש. מזהי UUID וחותמות זמן מאפשרים להוסיף סנכרון בהמשך. בדפדפן: IndexedDB. |
| מצלמה/גלריה | **expo-image-picker** + **expo-image-manipulator** | ממשק המצלמה והגלריה של המערכת; תיקון כיוון (EXIF) והקטנה ל-2048 פיקסלים. |
| שירות ענן (אופציונלי) | שרת Node קטן ב-`server/` | מחזיק את מפתחות ה-API בצד השרת בלבד. |

## ארכיטקטורה

```
src/
  app/            מסכים (Expo Router) – ממשק משתמש בלבד
  components/     רכיבי UI נגישים (כפתורים, מחוון, דיאלוגים, טיפים)
  editor/         עורך ההדמיה: Composition (רינדור), EditorCanvas (מחוות), useDesignEditor
                  (מצב + ביטול/ביצוע מחדש + שמירה אוטומטית), panels/ (כלים לפי סוג), exporter (ייצוא)
  imaging/        עיבוד תמונה מקומי: הסרת רקע, זיהוי משטח לפי צבע, צבע, גאומטריה/הומוגרפיה
  services/       מצלמה/גלריה (הרשאות), שיתוף/גלריה, לקוח לשירות הענן
  storage/        db.ts (מאגר נתונים + מנוי לשינויים), imageStore (קבצים / IndexedDB)
  model/          טיפוסים וקטגוריות
  demo/           טעינה והסרה של נתוני הדגמה
server/           שרת Proxy אופציונלי לשירותי AI (ללא תלויות)
```

**הפרדה:** מסכים לא ניגשים לאחסון או לפיקסלים ישירות; הם משתמשים ב-`storage/*`, `imaging/*` ו-`services/*`.
רכיב `Composition` "טהור" (מקבל תמונות טעונות) ולכן אותו קוד משמש לעורך, להשוואה ולייצוא ברזולוציה מלאה.

**מניעת אובדן עבודה:** כל שינוי בעורך נשמר מקומית תוך פחות משנייה, ובמעבר לרקע – מיד.
"שמירה" מעדכנת תמונה ממוזערת, "גרסה חדשה" משכפלת – הגרסה הקודמת לא נדרסת.

**פרטיות והרשאות:** הרשאת מצלמה מתבקשת רק כשלוחצים "צילום"; בחירה מהגלריה משתמשת בבוחר המערכת (בלי גישה לכל התמונות);
הרשאת שמירה לגלריה – רק כששומרים. תמונות לא נשלחות לשום שרת, אלא אם המשתמש הפעיל שירות ענן בהגדרות,
אישר את ההסבר, **וגם** לחץ על פעולת ענן (לתמונת חדר – אישור נוסף בכל פעם).

## מה נבדק בפועל

נבדק בדפדפן Chromium (Playwright, מסך טלפון 390×844) על השרת של Expo, עם העלאת קבצים אמיתית:

1. פתיחה ← יצירת חדר והעלאת תמונה ← בחירת מיקום וקטגוריה ← העלאת תמונת מוצר מ"חנות" (עם מדפים, ארון ותווית מחיר).
2. הסרת רקע אוטומטית (הספה נחתכה נקי; המדפים, הארון והצל הוסרו) ← מברשת מחיקה ← "סיום" ← הספה מוצבת בחדר.
3. גרירה בעורך, ביטול וביצוע מחדש, שמירה, יצירת גרסה חדשה (הקודמת נשמרה), טעינה מחדש של הדף – הנתונים נשארו.
4. צבע קיר: "זיהוי לפי צבע" בנגיעה על הקיר ← בחירת צבע – התמונה והחלון העליון נשארו מוגנים, והצללים נשמרו.
5. אריחים: בחירת אזור דוגמה ← משטח רצפה בפרספקטיבה ← הנחה באלכסון.
6. "אני בחנות עכשיו" ← חדר שמור ← מנורה ← הסרת רקע ← אור קר/חם (מסומן "המחשה בלבד").
7. השוואה (שתי אפשרויות, ולפני/אחרי עם קו מחיצה), ייצוא שלוש תמונות (סופית, לפני/אחרי, השוואה) – הקבצים נבדקו.
8. רשימת קניות לפי חדר, טעינה והסרה של נתוני ההדגמה, מחיקת כל הנתונים.
9. שירות ענן במצב דמה: בדיקת חיבור, דיאלוג אישור, שליחה וקבלת תוצאה. בדיקות השרת: `cd server && npm test`.

**לא נבדק בסביבה הזו:** הרצה על מכשיר iPhone/אנדרואיד פיזי או אמולטור (אין כאלה בסביבה), מצלמה אמיתית,
שיתוף בגיליון השיתוף של המערכת ושמירה לגלריה בטלפון (בדפדפן זה נבדק כהורדת קובץ), וחיבור ל-remove.bg עם מפתח אמיתי.
מומלץ לעבור על הזרימה בטלפון לפני הפצה.

## שירות הענן (אופציונלי)

ראו [`CAPABILITIES.md`](CAPABILITIES.md) לפירוט מלא. בקצרה:

```bash
cd server
npm run mock                           # מצב דמה – לבדיקת החיבור בלבד
REMOVE_BG_API_KEY=xxxx npm start       # הסרת רקע אמיתית דרך remove.bg
```

באפליקציה: הגדרות ← "עיבוד בענן" ← הפעלה ← כתובת השרת (למשל `https://api.example.com`) ← "בדיקת חיבור ושמירה".
בטלפון, `localhost` מצביע על הטלפון עצמו – צריך כתובת של המחשב ברשת המקומית (`http://192.168.x.x:8787`) או שרת מאובטח (HTTPS).

## מגבלות ידועות

* הסרת הרקע המקומית עובדת טוב כשהמוצר בולט בצבעו מהרקע; ברקע עמוס או בצבעים דומים צריך לתקן במברשת, או להשתמש בשירות הענן.
* זיהוי המשטח המקומי מבוסס צבע ("שרביט קסמים"): חלונות לבנים או רהיטים בצבע הקיר עלולים להיכלל – הקטינו רגישות או השתמשו ב"מברשת הגנה".
* פרספקטיבה של אובייקט היא הטיה דו־ממדית בסיסית; אין שחזור תלת־ממדי של החדר.
* חישוב גודל אמיתי דורש קו ייחוס ("קנה מידה") ורוחב מוצר; הוא מדויק רק בעומק שבו סומן הקו.
